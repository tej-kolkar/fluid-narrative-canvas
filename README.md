# Service Animation Refine

Update only the right-side animation in the four-service section shown in my uploaded video. Preserve the existing layout, text, colours, navigation, and service tabs.

Replace the abstract shapes with one clean laptop animation controlled by scrolling:

1. Brand Launch: laptop opens, showing “YOUR BRAND”.

2. Brand Repositioning: screen elements rearrange into a polished website.

3. Brand Reinvention: the interface separates into three floating layers, transforms, then reassembles.

4. Brand Elevation: a matching mobile screen and two campaign cards appear beside the laptop.

Use matte ivory devices, green screens, and subtle gold accents. Keep it minimal, premium, and client-focused. Scroll backward should reverse the transitions; service tabs should select the corresponding state.

Use lightweight CSS/SVG and existing animation tools; avoid heavy 3D libraries. Make it responsive. Implement in one focused pass without unrelated changes.
